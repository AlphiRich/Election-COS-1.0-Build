How a conflict is decided

Per field, last write wins — not per document. A canvasser correcting a phone number does not revert the sentiment a ward lead recorded ten minutes earlier; each field wins its own contest, using a _fieldUpdatedAt map kept on the server.

  • Equal timestamps keep the server's value, so a retry reaches the same answer.
  • A field the server has no timestamp for loses to any incoming value.
  • The losing value is not discarded silently: the device records yours and theirs in conflicts with resolved: false, for a person to review.
